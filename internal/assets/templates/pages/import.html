导入顺序很重要：先导产品，再导进货，最后导出库。 产品和进货进来之后，库存会自动算出来；如果产品里同时填了「期初库存」， 系统检测到该产品已有流水时会自动跳过期初，避免数量翻倍。
1产品档案 含期初库存
可识别的列名
产品编码 / 条形码 / 产品名称 / 货品简称 / 品类 / 品牌 / 产地 / 单位 / 参考成本 / 建议售价 / 库存预警线 / 供应商 / 期初库存 / 备注
按「产品编码」或「条形码」匹配：已存在就更新，不存在就新建。供应商不存在会自动建。
2进货明细 自动确认入库
可识别的列名
日期 / 供应商 / 产品编码 / 产品名称（或货品简称）/ 数量 / 单价 / 备注
同一天同一供应商的行会合并成一张采购单并直接确认入库； 单价留空时按产品参考成本计价。
3出库明细 市集销售 / 试饮 / 损耗 / 调拨
可识别的列名
市集名称 / 日期 / 产品编码 / 产品名称（或货品简称）/ 类型 / 数量 / 单价 / 备注
类型填「销售 / 试饮 / 赠送 / 损耗」才算市集现场记录； 填「调拨 / 盘亏」或不填市集名称时走手工出库登记。 市集不存在会按名称自动创建。
导入后要到「市集活动」里逐场点「结算」，结算才会扣减库存—— 这是系统的设计：每场市集的成本与利润在结算时才定下来。
导入前请先做一次备份
导入会直接写入数据库。虽然重复导入同一文件不会产生重复数据， 但第一次导入前建议先到 系统设置 点一次「立即备份」， 万一映射不对可以随时下载备份回到导入前的状态。
